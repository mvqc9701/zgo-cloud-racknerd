## 一、RackNerd：便宜到让人怀疑人生的那个

先说RackNerd，毕竟它出道更早，口碑更稳。2019年成立，到现在六七年，愣是从被怀疑"会不会跑路"的小商家，熬成了Inc.杂志认证、海内外玩家都点名推荐的"廉价机皇"。

它最大的特点就是便宜，而且便宜得理直气壮。你看它2026年的常规促销套餐，1核1G内存、20G SSD、3T月流量、1Gbps带宽，年付只要$21.99——续费还是这个价，不是那种"首年便宜续费翻倍"的套路。再往上走，2核2G/35G/5T是$35.99/年，4核3G/60G/7T是$59.99/年，配置和价格的配比相当厚道。

机房也多。洛杉矶、圣何塞、西雅图、芝加哥、达拉斯、纽约、阿什本，再加上欧洲的阿姆斯特丹和斯特拉斯堡，整整十来个点。对国内用户来说，优先选西海岸的洛杉矶、圣何塞、西雅图，物理距离近，延迟天然占优。

不过RackNerd的线路是常规的中国大陆BGP直连，没有特别的电信9929、联通CUII、移动CMIN2这种高端优化。日常用没问题，但晚高峰偶尔会有点抖，对延迟敏感的业务（比如科学上网、直播转发）就要自己心里有数了。

还有一个被玩家津津乐道的点：RackNerd的促销套餐卖完不补货，买到的就成"传家宝"了。这意味着早期入坑的人锁住了低价，后来的人只能看新一批促销，价格年年微涨是趋势——所以能早买就别拖。
